# P50 / P90 energy estimate (preliminary)

P50 = PVsyst variant VC4 (8.0 m pitch) annual energy injected = **7,078 MWh/yr**

| Uncertainty component | σ (%) |
|---|---|
| Irradiance data source (Meteonorm vs PVGIS vs NASA POWER spread) | 5.0 |
| Interannual GHI variability (Meteonorm, PVsyst) | 3.2 |
| Transposition and bifacial model | 2.0 |
| PV performance model (temperature, low-light, IAM) | 2.0 |
| Module data and degradation behaviour | 1.5 |
| Soiling assumption | 1.0 |
| Availability assumption | 0.5 |

| Case | Combined σ (%) | P90 (MWh/yr) | P90 / P50 |
|---|---|---|---|
| 1-year | 6.84 | 6,458 | 0.912 |
| 10-year | 6.13 | 6,522 | 0.921 |

Method: RSS of independent components, P90 = P50 × (1 − 1.2816 σ). The 10-year case divides the interannual component by √10.
All σ values are assumptions, to be revisited; the largest (data source, 5%) reflects the spread between the three irradiance datasets (1,574 to 1,730 kWh/m²).
