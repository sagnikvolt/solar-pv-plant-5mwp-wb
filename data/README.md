# Data

- `site.md`: site selection and justification
- `weather/weather_comparison.csv`: monthly GHI and temperature from three sources (run `python calcs/weather_compare.py`)
- `datasheets/`: module and inverter datasheets (PDF) for the selected equipment, plus a screenshot of the ALMM listing

Sources:
- PVGIS: https://re.jrc.ec.europa.eu/pvg_tools/en/
- NASA POWER: https://power.larc.nasa.gov/data-access-viewer/
- ALMM List-I (MNRE): https://mnre.gov.in
