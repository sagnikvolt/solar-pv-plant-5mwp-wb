# Report (6–8 pages)

Planned outline:
1. Executive summary: key numbers table
2. Site and solar resource: site justification and the three-source irradiance comparison
3. Equipment selection: module (ALMM/DCR context), inverter, DC/AC ratio
4. Array design: tilt, pitch, string sizing (with the calculation table)
5. Energy yield: PVsyst results, loss diagram, PR, P50/P90, SAM/PVGIS cross-check
6. Electrical design: cable sizing, SLD and 33 kV evacuation concept
7. BOQ and economics: capex, LCOE, payback, CO₂
8. Limitations and next steps
Appendix: assumption log, PVsyst report

Final file: `SPV5_Design_Report.pdf`
